# Dataset de muestra

Aquí vivirá un conjunto pequeño y saneado de catálogos para desarrollo y CI:

- `select.out` de Seisan
- `eventquery_*.csv`
- export de SeisComp (`seiscomp_*.csv`)

Debe ser reproducible, sin datos sensibles y lo bastante pequeño para correr en
segundos. Se construirá en la etapa 1 a partir de los fixtures de
`revisacatalogosweb/verificacion/`.
